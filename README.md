# VM Agency Website

Corporate website developed for **VM Agency**, focused on presenting the company's services, methodology, success stories and contact information through a modern, responsive and high-performance website.

## 🚀 Overview

This project is a fully responsive corporate website built with **HTML, CSS and JavaScript**, following modern UI/UX principles and a clean component-based structure.

The website has been designed to provide an intuitive user experience across desktop, tablet and mobile devices while maintaining excellent performance and accessibility.

## ✨ Features

- Responsive design (Desktop, Tablet & Mobile)
- Modern and minimalist UI
- Multi-language support
  - 🇪🇸 Spanish
  - 🇬🇧 English
  - 🇧🇬 Bulgarian
- Optimized semantic HTML5
- Modular CSS architecture
- Vanilla JavaScript
- Reusable components
- Smooth animations
- SEO friendly
- Accessibility focused
- Optimized images and assets

## 🛠 Technologies
